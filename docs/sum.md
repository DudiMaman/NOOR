## מהות הפרויקט

**NOOR** היא אפליקציית מנויים (Subscription) פרימיום בתחום האיסלאם, בנויה ב-**React Native (Expo SDK 57, TypeScript strict)**, בעברית-פיתוח אך **ערבית-תחילה ו-RTL מלא** למשתמש הקצה. האפליקציה מלווה את המשתמש לאורך היום הדתי שלו: זמני תפילה מדויקים, התראות חכמות, קריאת קוראן מלאה עם תלאווה, אדכאר בוקר/ערב/אחרי-תפילה בטקסטים מלאים, מדריכי "איך מתפללים" צעד-אחר-צעד, חדית' יומי עם הסבר, וחגים ומועדים היג'ריים.

העיצוב מומש פיקסל-לפיקסל מ-handoff של **Claude Design** (19 מסכים, נמצא בתיקיית `design/`), כולל כל האנימציות האמביינטיות (שמש נעה על קשת, רדאר פועם, ערימת קלפים, אורביטות זהב, shimmer).

## מודל עסקי

- הכל בתשלום: מסך ה-Paywall נסגר ב-✕, אבל **כל טאב/כפתור/פיצ'ר** שמשתמש חינמי נוגע בו מרים את ה-Paywall מחדש (`usePaywallGate`), עם הצעת **3 ימי ניסיון חינם**.
- חריגים מכוונים: צפייה פסיבית במסך הבית, וטאב ההגדרות (כדי ש"ניהול מנוי" ו"שחזור רכישה" יישארו נגישים — כל שורת פיצ'ר בתוכו מנוטרלת בנפרד).
- תמחור: **שנתי $59.99** (≈$4.99/חודש, "חסוך 50%") / **חודשי $9.99** — מוגדר בדולר ומוצג במטבע המקומי של המשתמש.
- הרכישה כרגע mock מרוכז ב-`useSubscriptionStore` — מוכן לחיבור StoreKit / Play Billing / RevenueCat ללא נגיעה במסכים.

## ארכיטקטורה בקצרה

```
src/
  components/   ספריית UI משותפת (theme-aware)
  content/      תוכן קדוש בערבית: קוראן (JSON ארוז), אדכאר, חדית', מדריכי תפילה, ערים
  hooks/        usePaywallGate · usePrayerSchedule · useNow
  i18n/         i18next, 21 locales, זיהוי שפת מכשיר, סנכרון RTL
  navigation/   Stack ראשי + טאבים עם gating
  screens/      onboarding/ quiz/ auth/ paywall/ main/ reader/ settings/
  services/     prayerTimes · hijri · notifications · audio · currency · auth · pushToken · islamicEvents
  store/        zustand persisted: user · settings · subscription · content
  theme/        טוקני עיצוב + פלטות light/dark + ThemeProvider
```

מסמך העומק: [`docs/ARCHITECTURE.md`](ARCHITECTURE.md) · יומן השיחה: [`docs/chat.md`](chat.md)

## הרצה והדגמה

```bash
npm install
npx expo start        # סריקת ה-QR שמוצג — עם אפליקציית Expo Go בטלפון
```

- **QR לריפו:** [`docs/qr-repo.png`](qr-repo.png) — סריקה מובילה לריפו בגיטהאב.
- **QR חי של האפליקציה:** מוצג בטרמינל בעת `npx expo start` (או `--tunnel` לרשת חיצונית) — ראו [`docs/QR.md`](QR.md).
