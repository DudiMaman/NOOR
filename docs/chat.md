## הודעה 1 · המשתמש (2026-07-02, פתיחת הפרויקט)

**תמצית הבקשה (ULTRACODE):**
- שם האפליקציה: **NOOR** · טכנולוגיה: **React Native** · סוג מוצר: אפליקציית **Subscription** בתחום האיסלאם.
- צורף קובץ ZIP עם העיצוב המלא מ-Claude Design — להעלות את העיצוב לריפו ולממש את האפליקציה בנאמנות מלאה ל-UI/UX/צבעוניות/טיפוגרפיה/מרווחים/זרימה.
- מהות: תפילות, קיום מצוות, מנהגים, קוראן, צדקה, חגים, זמני תפילה ותוכן איסלאמי יומי. כשההתראה קופצת (למשל תפילת בוקר) — התפילה המלאה חייבת להופיע בעמוד בכתב ערבי.
- **חוקיות Paywall:** כל האפליקציה בתשלום. מסך ה-Paywall נסגר ב-X, אבל כל טאב/כפתור/פיצ'ר שהמשתמש נוגע בו מרים את ה-Paywall מחדש עם 3 ימי ניסיון חינם. מחיר בדולר, מוצג במטבע המקומי.
- מטרות: אפליקציה מלאה ויציבה, חוויית משתמש מכירתית, דגש על Onboarding/הרשמה/התחברות/מנוי/Paywall, קוד מודולרי, הכל בגיטהאב.
- מבנה מומלץ: Onboarding, Splash, הרשמה/התחברות, בית, תוכן יומי, תפילות, מצוות ומנהגים, זמני תפילה, התראות Push, מנוי/Paywall, פרופיל, הגדרות, ניהול התראות, תוכן נעול/פתוח.
- **שפות:** ברירת מחדל ערבית + ~20 תרגומים + בחירת שפה בהגדרות + רכיב זיהוי שפת מכשיר בהשקה (פופ-אפ מגירה: "לעבור ל-X / להישאר בערבית").
- לעבוד אוטונומית עד השלמה, לתעד החלטות, README מסודר, commit + push.

## תגובת Claude · שלב 1 — בניית האפליקציה המלאה

1. **חילוץ העיצוב** — קובץ ה-ZIP נפרס: handoff של 19 מסכים (HTML) + README עיצובי מפורט (טוקנים, טיפוגרפיה, אנימציות). הועלה לריפו תחת `design/`.
2. **סקאפולד** — Expo SDK 57 / RN 0.86 / TypeScript strict; תוקנה תקלת `.git` שנדרסה; הענף `claude/noor-islamic-app-dev-0vros3` שוחזר ונדחף.
3. **תשתית ליבה** — טוקני עיצוב (`src/theme`), i18n עם 21 שפות (ar ברירת מחדל) + פופ-אפ זיהוי שפת מכשיר, ארבעה סטורים (zustand+persist), שירותים (adhan, היג'רה, התראות מקומיות, מטבע USD→מקומי), ניווט מלא + טאב-בר מותאם עם חסימת Paywall, ספריית קומפוננטות (כפתורים, קלפים, טוגלים, כוכב 8 קצוות, אנימציות Reanimated לפי keyframes של העיצוב), הוק `usePaywallGate`.
4. **פריסה מרובת-סוכנים (36 סוכנים):** 4 סוכני תוכן (קוראן, אדכאר מלאים עם מקורות, 27 חדית'ים עם הסברים, מדריכי תפילה מלאים לכל 5 התפילות), 13 סוכני מסכים (Splash, Onboarding×4 עם כל אנימציות ההירו, Quiz×4, Trial Paywall, Subscription Paywall, Location, Auth, Home, Prayer Times, Quran Reader+Surah List, Customs+Daily Content, Reminders, Settings+Profile+Language, Adhkar Reader+Prayer Guide), 19 סוכני תרגום (כל קובץ locale אומת מבנית מול en.json).
5. **אימות** — tsc נקי, כל 21 קובצי השפה עקביים (333 מפתחות), `expo export` בנה bundle תקין.
6. **ביקורת אדוורסרית (5 סוכנים):** לוגיקת Paywall, נאמנות עיצובית מול ה-HTML, RTL/i18n, שלמות ניווט, באגי ריצה. כל הממצאים המאומתים תוקנו — כולל: פתיחת טאב הגדרות למשתמש חינמי (כדי ש"ניהול מנוי" ו"שחזור רכישה" יהיו נגישים), באג hydration בעליה קרה, ערוצי התראות אנדרואיד, תיקון אלגוריתם היג'רה (אומת נומרית), סמני פסוקים עגולים בקורא, נקודות כניסה למסכים שהיו בלתי-נגישים, ועוד ~20 תיקונים.
7. **סיום שלב 1** — README מקיף, ~18 קומיטים, הכל נדחף לענף.

## תגובת Claude · שלב 2 — השלמת כל הפערים

1. **קוראן מלא** — הורדת הטקסט העות'מאני המלא (Tanzil דרך alquran.cloud), 114 סורות / 6,236 פסוקים, נכס JSON ארוז (1.4MB) עם הסרת בסמלה נכונה; הקורא שודרג לרשימה וירטואלית (chunks של 12 פסוקים) ורשימת הסורות ל-FlatList עם חיפוש.
2. **תלאווה אמיתית** — expo-audio בסטרימינג מ-CDN של islamic.network: 4 קוראים (אלעפאסי, עבד אלבאסט, אלמעיקלי, אלחוסרי), ניגון/השהיה/seek/החלפת קורא.
3. **Dark Mode מלא** — פלטה כהה נגזרת מהטוקנים, ThemeProvider עם מצב auto (עוקב מערכת), רפקטור כל 23 המסכים והקומפוננטות ל-`useTheme()` (6 סוכני רפקטור במקביל); מסכי ההירו הכהים נשארו זהים בשני המצבים.
4. **תאריכי אום אל-קורא רשמיים** — `@umalqura/core` עם אימות מול תאריכי העוגן (17 מוחרם 1448 = 2.7.2026) + fallback טבלאי.
5. **חשבונות אמיתיים (local-first)** — רישום עם hash מלוח SHA-256 (expo-crypto), אימות סיסמה אמיתי, שגיאות ייעודיות ב-21 שפות, מוכן להחלפה ב-backend.
6. **תשתית Push מרוחק** — רישום Expo push token ושמירתו (שליחה בפועל דורשת שרת).
7. **ליטוש** — אייקונים ממותגים (כוכב 8 קצוות על אמרלד) לכל הפלטפורמות + splash + favicon, `eas.json`, תיקון זרימת "מילוי שאלון מחדש", 24 בדיקות יחידה (Jest) לשכבת השירותים — כולן עוברות, tsc נקי, bundle מאומת (5.8MB).
8. הכל בקומיטים מסודרים ונדחף. **פתוח בכוונה:** חיבור תשלומים אמיתי בלבד.
