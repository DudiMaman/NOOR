## 2. הרצת האפליקציה החיה בטלפון (Expo Go)

ה-QR שמריץ את האפליקציה עצמה נוצר על-ידי שרת הפיתוח של Expo ולכן תלוי במכונה שמריצה אותו
(הוא מקודד את כתובת ה-IP/מנהרה של אותה מכונה) — אי אפשר להצמיד אותו סטטית לריפו.
כדי לקבל אותו:

```bash
git clone https://github.com/DudiMaman/NOOR.git
cd NOOR
npm install
npx expo start            # באותה רשת Wi-Fi עם הטלפון
# או, מרשת אחרת:
npx expo start --tunnel
```

1. מתקינים את **Expo Go** מה-App Store / Google Play.
2. סורקים את ה-QR שמופיע בטרמינל (iOS: מצלמת המערכת; Android: מתוך Expo Go).
3. האפליקציה נטענת עם הפלואו המלא: Splash → Onboarding → שאלון → הרשמה → Paywall (ניסיון 3 ימים) → מיקום → האפליקציה המלאה.

> טיפ להדגמה מלאה: לחצו ✕ ב-Paywall כדי לראות את חוקיות ה-gating (כל נגיעה מחזירה את ה-Paywall),
> או "ابدأ 3 أيام مجانًا" כדי לפתוח את הכל. החלפת שפה ומצב תצוגה (בהיר/כהה) — במסך ההגדרות.

## 3. בנייה קבועה (ללא מחשב מארח)

לחוויה קבועה שאינה תלויה בשרת פיתוח, בונים עם EAS (פרופילים מוכנים ב-`eas.json`):

```bash
npx eas build --profile preview --platform android   # מפיק APK להתקנה ישירה + QR הורדה
npx eas update                                        # פרסום OTA שנטען דרך Expo Go / dev client
```

שתי הפקודות דורשות חשבון Expo (חינמי) והרשאות לפרויקט.
